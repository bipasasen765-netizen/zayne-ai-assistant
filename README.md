## ✨ Features

- 🎙️ Voice input using the browser Speech Recognition API
- 🔊 Voice responses using Speech Synthesis
- 🤖 Gemini-powered AI conversation
- 💬 WhatsApp automation through GREEN-API
- 🗄️ Supabase contact lookup
- 🎵 YouTube music playback
- 🎬 YouTube video playback
- 🌐 English / Hindi voice modes
- ✨ Cinematic UI with a 150-frame interactive hero sequence
- 🖱️ Scroll, drag and trackpad interactions
- 🎨 Shader-based visual effects
- 📱 Responsive interface

# 🧰 Tech Stack

| Technology | Purpose |
|---|---|
| Next.js | Full-stack React framework and API route |
| React | UI and state management |
| Tailwind CSS | Styling |
| Gemini API | AI responses |
| Supabase | Contact lookup / backend data |
| GREEN-API | WhatsApp message dispatch |
| Web Speech API | Voice recognition |
| Speech Synthesis API | Voice responses |
| GSAP | Animation |
| ShaderGradient | Shader visual effects |
| Lucide React | Icons |
| YouTube | Music / video playback |
